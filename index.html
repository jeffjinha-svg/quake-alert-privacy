지진 경보 개인정보처리방침

앱 이름: 지진 경보 · 시행일: 2026년 8월 21일

요약 — 이 앱은 개인정보를 수집하지 않습니다. 위치 정보는 지진 경보를 계산하기 위해 기기 안에서만 사용하며, 개발자를 포함해 어디로도 전송되지 않습니다.

1. 수집하는 정보

이 앱은 개인정보를 수집하지 않습니다. 개발자는 이용자의 어떠한 정보도 전송받거나 저장하지 않으며, 이용자 계정이나 로그인 절차가 없습니다.

2. 기기 안에서만 사용하는 정보

  • 위치 정보 — 지진 발생 시 이용자가 있는 곳의 예상진도를 계산하고, 가까운 대피소를 찾기 위해 사용합니다. 위치는 기기 내부에만 저장되며 외부로 전송되지 않습니다.
    이용자가 위치 권한을 ‘항상 허용’으로 설정한 경우, 앱이 실행 중이지 않을 때에도 15분마다 위치를 확인해 기기에 저장합니다. 지진 경보는 앱을 보고 있지 않을 때 도착하는데, 안드로이드는 앱이 화면에 없는 동안에는 위치를 측정하지 못하게 하므로 미리 확인해 두어야 하기 때문입니다.
    설정에서 ‘고정 위치’를 선택하면 위치 정보를 전혀 사용하지 않습니다.
  • 알림 내역 — 수신한 지진 알림을 기기에 최대 300건까지 보관합니다. 앱 안에서 언제든 지울 수 있으며 외부로 전송되지 않습니다.
  • 설정값 — 경보 문턱, 소리, 진동 등 이용자가 정한 설정을 기기에 저장합니다.

3. 외부와 주고받는 정보

  • 지진 경보 수신 — Google Firebase Cloud Messaging을 통해 지진 경보를 받습니다. 이용자는 익명 토픽을 구독하며, 개발자는 어떤 이용자가 구독 중인지 알 수 없습니다. 이 통신에는 위치가 포함되지 않습니다.
  • 대피소 목록 — 중계 서버에서 전국 대피소 목록을 통째로 내려받아 기기에 저장합니다. 거리 계산은 기기 안에서 이뤄지므로, 서버는 이용자가 어디에 있는지 알지 못합니다.
  • 서버 상태 확인 — 이용자가 점검 화면에서 직접 눌렀을 때만 중계 서버의 동작 상태를 조회합니다. 이 요청에는 어떤 식별 정보도 포함되지 않습니다.

위 세 가지가 이 앱이 외부와 주고받는 통신의 전부이며, 모두 HTTPS로 암호화됩니다.

4. 정보의 출처

  • 지진 정보 — 기상청 공식 오픈 API (API허브, 공공데이터포털)
  • 대피소 정보 — 행정안전부 재난안전데이터공유플랫폼

5. 제3자 제공

개인정보를 수집하지 않으므로 제3자에게 제공하는 정보가 없습니다. 경보 전달에 사용하는 Firebase Cloud Messaging의 데이터 처리는 Google의 개인정보처리방침을 따릅니다.

6. 이용자의 권리

  • 앱 설정에서 ‘고정 위치’로 바꾸면 위치 정보를 전혀 사용하지 않습니다.
  • 안드로이드 설정 → 앱 → 지진 경보 → 권한에서 위치 권한을 언제든 해제하거나 ‘앱 사용 중에만 허용’으로 낮출 수 있습니다. 권한을 해제해도 앱의 다른 기능은 그대로 사용할 수 있습니다.
  • 알림 내역은 앱 안에서 전체 삭제할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 정보가 함께 삭제됩니다. 개발자가 따로 보관하는 정보는 없습니다.

7. 아동의 개인정보

이 앱은 나이에 관계없이 어떠한 이용자의 개인정보도 수집하지 않으므로, 아동의 개인정보를 수집하는 일도 없습니다. 법정대리인 동의가 필요한 수집 행위 자체가 존재하지 않습니다.

이 앱은 아동을 주 대상으로 설계되거나 홍보되지 않으며, Google Play 의 타겟 연령대는 만 13세 이상으로 설정되어 있습니다. 다만 이는 이용 제한이 아닙니다. 지진 경보는 나이를 가리지 않아야 하는 정보이며, 아동이 보호자의 기기나 본인의 기기에서 이 앱의 경보를 받는 데에는 아무런 제한이 없습니다.
